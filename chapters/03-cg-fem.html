3Continuous finite elements

From the weak form to a sparse linear system: meshes, basis functions, reference elements, assembly and solvers — for the 2D Poisson problem.

Chapter 2 turned $-\Delta u = f$ into the weak form $a(u,v) = \ell(v)$ and the Galerkin method into a linear system $A\mathbf U = \mathbf b$ with $A_{ij} = \int\nabla\varphi_j\cdot\nabla\varphi_i$. What remains is engineering: choose a mesh and basis functions with small supports, compute the integrals element by element, and solve the resulting sparse system. This is the continuous Galerkin (CG) finite element method, the workhorse of structural mechanics, heat transfer and electromagnetics.

Meshes

We cover $\Omega$ by triangles that meet only at whole edges or vertices — a conforming triangulation, exactly the "watertight mesh without T-junctions" that rasterisers and geometry processing also prefer. The mesh size $h$ is the largest element diameter; refining the mesh means $h\to0$. The quality of the triangles matters: the error constants grow when angles approach 180°.

Piecewise polynomials and their basis functions

The simplest CG space, $V_h^1$, contains all continuous functions that are linear on each triangle. Such a function is determined by its values at the vertices, so the natural basis consists of hat functions $\varphi_j$: $\varphi_j = 1$ at vertex $j$, $0$ at all other vertices, linear in between. On a triangle with vertices $\mathbf v_0, \mathbf v_1, \mathbf v_2$ the three hat functions that are nonzero there are exactly the barycentric coordinates $\lambda_0, \lambda_1, \lambda_2$ — the weights $\mathbf x = \lambda_0\mathbf v_0 + \lambda_1\mathbf v_1 + \lambda_2\mathbf v_2$, $\sum\lambda_i = 1$, that a GPU uses to interpolate vertex attributes. A P1 finite element function is a Gouraud-shaded mesh.

For more accuracy we use piecewise quadratics $V_h^2$: six nodes per triangle (vertices and edge midpoints), with basis functions $\lambda_i(2\lambda_i - 1)$ at vertices and $4\lambda_a\lambda_b$ at the midpoint of edge $ab$. Neighbouring triangles share edge nodes, which keeps the function continuous.

The reference element and the affine map

Every triangle $K$ is the image of the reference triangle $\hat K$ under the affine map

$$F_K(\hat{\mathbf x}) = \mathbf v_0 + J\hat{\mathbf x},\qquad J = \big[\,\mathbf v_1 - \mathbf v_0 \;\big|\; \mathbf v_2 - \mathbf v_0\,\big] \in\R^{2\times2}.$$

Basis functions are defined once on $\hat K$ and transported: $\varphi(\mathbf x) = \hat\varphi(F_K^{-1}(\mathbf x))$ — the "texture coordinates" of the element. Two formulas convert integrals and derivatives:

  • Area element: $\int_K g\dd\mathbf x = \int_{\hat K} g(F_K(\hat{\mathbf x}))\,|\det J| \dd\hat{\mathbf x}$, with $|\det J| = 2|K|$.
  • Gradients (chain rule): $\hat\nabla\hat\varphi = J^T\nabla\varphi$, hence $\nabla\varphi = J^{-T}\hat\nabla\hat\varphi$.

So all integrals become integrals over $\hat K$, computed with one fixed quadrature rule: $\int_{\hat K} \hat g \approx \sum_q w_q\,\hat g(\hat{\mathbf x}_q)$ (our rules are exact for polynomials up to a chosen degree; see lib/core/quad/simplex.js).

Assembly: building the matrix element by element

Because integrals split over elements, $A_{ij} = \sum_{K} \int_K \nabla\varphi_j\cdot\nabla\varphi_i \dd\mathbf x$, and on each $K$ only the few basis functions living on $K$ are nonzero. The algorithm is a scatter-add:

for each element K:
    dofs = global indices of the local basis functions of K      # 3 for P1, 6 for P2
    K_loc = zeros(n_loc, n_loc);  b_loc = zeros(n_loc)
    for each quadrature point q of the reference triangle:
        compute x_q = F_K(x̂_q), weight w = w_q |det J|, gradients ∇φ_i = J^{-T} ∇̂φ̂_i
        K_loc[i][j] += w ∇φ_j·∇φ_i ;   b_loc[i] += w f(x_q) φ_i(x_q)
    A[dofs, dofs] += K_loc ;   b[dofs] += b_loc                 # scatter-add

For P1 the gradients are constant on $K$ and the local matrix has a classic closed form. If $\theta_k$ is the angle at the vertex opposite the edge $\{i, j\}$, then

$$K^{\text{loc}}_{ij} = -\tfrac12\cot\theta_k\quad (i\neq j),\qquad K^{\text{loc}}_{ii} = -\sum_{j\neq i}K^{\text{loc}}_{ij}.$$
Graphics analogy

This is the famous cotangent Laplacian of discrete differential geometry (Pinkall & Polthier 1993) used for mesh smoothing, parameterisation and deformation: it is literally the P1 finite element stiffness matrix. Rows sum to zero because constants have zero gradient. For obtuse angles the cotangent is negative and positive off-diagonal entries appear — the discrete maximum principle can then fail, which is why "Delaunay" meshes are preferred in both communities.

Boundary conditions and the linear system

The assembled matrix has a one-dimensional kernel (constants) until boundary conditions are imposed. With Dirichlet data $u = g$ the simplest way is elimination: boundary DOFs get their values $g(\mathbf x_j)$, their rows are dropped and their known contributions are moved to the right-hand side. What remains is a system that is

  • sparse: about 7 nonzeros per row for P1 on a regular mesh (each vertex couples to itself and its ~6 neighbours), stored in CSR format (row pointers, column indices, values — an adjacency list of the mesh graph);
  • symmetric positive definite (SPD): $\mathbf U^TA\mathbf U = \int|\nabla u_h|^2 > 0$;
  • ill-conditioned: $\kappa(A) \sim h^{-2}$. Halving $h$ quadruples the condition number.

Two families of solvers:

  • Direct (sparse Cholesky/LU). Elimination fills in entries only inside the matrix's band, so we first renumber the unknowns to make the band narrow: reverse Cuthill–McKee (RCM) is a breadth-first traversal of the mesh graph. On our structured grid the natural row-by-row numbering is already banded; a mesh generator typically produces an arbitrary ("random") numbering — compare both with RCM below.
  • Iterative: the conjugate gradient method needs only products $A\mathbf x$ and converges in $O(\sqrt{\kappa})= O(h^{-1})$ iterations. A preconditioner $M\approx A^{-1}$ reduces the count; multigrid or domain decomposition (chapter 10) make it independent of $h$.

Accuracy: what to expect

By Céa's lemma (chapter 2) the error is as small as the best approximation of $u$ by piecewise polynomials, and interpolation theory (chapter 0) gives, for smooth $u$,

$$|u - u_h|_{H^1} \le C\,h^{p}, \qquad \|u - u_h\|_{L^2}\le C\,h^{p+1}.$$

The extra order in $L^2$ comes from a duality argument (Aubin–Nitsche): the error is tested against the solution of an auxiliary Poisson problem, which is again approximated well. Both rates are verified live below and in the test suite.

What goes wrong
  • Forgetting $|\det J|$ or using $J^{-1}$ instead of $J^{-T}$: results look plausible on uniform meshes (where errors partially cancel) and break on distorted ones. Always test on distorted meshes.
  • Too low quadrature order for the load $\int f\varphi_i$: the rate silently drops. We use rules exact for degree $2p+3$ for assembly and $2p+6$ for error norms.
  • Degenerate triangles (angles near 180°): huge entries, bad conditioning, large error constants.

Summary

  • CG FEM = Galerkin with continuous piecewise polynomials on a mesh; P1 basis = barycentric coordinates.
  • All work happens on a reference element: $\int_K g = \int_{\hat K} g\circ F_K\,|\det J|$, $\nabla\varphi = J^{-T}\hat\nabla\hat\varphi$.
  • Assembly = loop over elements + scatter-add; P1 stiffness = cotangent Laplacian.
  • The system is sparse, SPD, with $\kappa\sim h^{-2}$; solve with sparse direct methods (after reordering) or preconditioned CG.
  • Error $O(h^p)$ in $H^1$ and $O(h^{p+1})$ in $L^2$ for smooth solutions.
